## 核心设计理念

**WinRouter** 是 Windows 双网卡智能分流软件，核心目标：
- 国内流量通过网卡 A 直连
- 其他公网流量通过网卡 B 直连或代理
- 本机/局域网按接口直连，DNS 与业务流量出口一致
- 配置驱动、最小权限、明确出口、可回滚、可观测

技术栈：Go 1.22+ / Wails / Vue 3 TypeScript / sing-box 1.13.15

## 已解决关键风险

| 风险 | 原因 | 解决方案 |
|---|---|---|
| 网卡标识不稳定 | 断开/重新连接后 GUID 丢失 | GUID 作为主标识，启动时重新验证并提示选择 |
| 私网前缀重叠 | 多个接口或虚拟网络 | 按接口分类、冲突检测；歧义时拒绝启动 |
| DNS 泄漏 | 系统 DNS 绕过 TUN | DNS 纳入 TUN 策略、明确出口绑定、防环路规则 |
| 代理环路 | 代理连接再入代理 | 服务器 IP `/32` 路由、网卡 B 绑定、endpoint 防环 |
| 核心崩溃循环 | 配置错误导致重启不止 | 有界指数退避（最多 7 次）、异常标记保留 |
| 提权滥用 | UI 越过 helper 权限边界 | 最小 RPC、ACL、身份校验、路径白名单 |

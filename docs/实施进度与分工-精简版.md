## 当前结论

- Phase 0：单环境网络可行性验证通过。
- Phase 1：双网卡直连 MVP 已实现并完成主要验收，可作为预览版基础；公开发布条件尚未满足。
- Phase 2：稳定性、监控和桌面体验已完成大部分实现，兼容性与长稳验证仍需补测。
- Phase 3：代理模式实现完成，但退出验收受真实外部 HTTP CONNECT 测试节点缺失阻塞。
- Phase 4：规则、进程分流及扩展能力已实现；性能、稳定性、安全和许可证退出检查未完成。

## 已交付能力

- Go/Wails/Vue 3 + TypeScript 工程、锁定依赖、CI、构建与测试入口。
- Windows 接口枚举、GUID 持久化、接口变化监听、候选过滤、重叠前缀和 TUN 前缀池诊断。
- `direct-split` 配置生成、四层校验、双出口 DNS、缓存隔离、DoH/DoT 防环路及 MVP IPv6 阻断策略。
- 按需提权 helper、Named Pipe ACL/RPC、核心版本哈希校验、原子配置替换、回滚和 Job Object 生命周期管理。
- 托盘、监控、诊断包、开机启动、休眠/唤醒和网卡掉线恢复等桌面体验能力。
- SRS 规则集、多来源 Geo 数据、可配置双出口 DNS、进程名称/路径分流、节点测速收藏、流量预算提醒和中英文界面。
- 高级修复中的 Windows 网络组件重置命令已加入白名单 RPC，并提供确认及重启警告。

## 关键决策

- 采用独立开发流程，以自动化测试、静态检查和可复现实验证据替代多人签字，不降低安全、网络清理和许可证门槛。
- MVP 默认采用真实 IP 与 IPv6 `block` 策略；IPv6 `split` 保留为后续能力，须完成独立双出口实测。
- Phase 1 以预览版口径发布，24 小时长稳测试不记为通过；正式稳定版前必须重新评估。
- 代理节点、远程状态查看和企业签名策略均不在证据不足时开放。

## 最近进展（2026-08-05）

- 修复托盘长期右键无响应：固定 Windows systray 消息泵线程、去重状态更新、异步菜单动作，并增加双击显示/隐藏主窗口。
- 增加“重置 Windows 网络组件”高级修复：停止核心后由 helper 按白名单执行 Winsock/IP/DNS 重置，返回分步结果；设置页增加二次确认和重启警告。
- RPC、执行顺序、托盘双击回归测试及 Go/前端/Windows 构建均通过。
- 待在真实用户环境验证托盘交互、网络重置后的重启及静态网络配置恢复，并收集微信 CDN 出口规则复现证据。

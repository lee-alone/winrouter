# Phase 4 增强功能使用与回滚

本文说明 Phase 4 已开放能力的启用、停用、回滚、数据迁移和已知限制。远程状态查看和签名企业策略仅完成安全评估，当前没有运行时入口。

## IPv6 分流策略

- 在“设置”页使用 IPv6 分流开关。默认关闭（`block`）：AAAA 查询和经 TUN 的 IPv6 流量被拒绝，IPv6 前缀重叠不会阻断 IPv4 双出口分流。
- 停止核心后才可切换。开启（`split`）时，预检要求出口 A/B 都有可用 IPv6 地址和 IPv6 默认路由，并拒绝任何跨出口 IPv6 前缀重叠；通过后 AAAA 和 IPv6 直连前缀进入正常的 DNS/路由策略。
- 关闭开关并保存即可回滚到阻断策略；旧接口状态 Schema 1/2 自动迁移为 `block`。

限制：`split` 已通过模型、语义、Go 单元测试及前端生产构建，但尚未完成双独立 IPv6 出口的物理抓包、DNS/TCP/UDP 和恢复验收，不作为当前预览环境的默认功能。

## 自定义规则与远程规则集

- 在“规则”页添加域名后缀、IPv4 CIDR、进程名称或进程完整路径规则，并选择出口 A、出口 B、当前模式最终出口或拒绝。
- 删除或禁用对应规则后重新应用配置即可停用。应用失败时核心保留上一份健康配置；删除全部用户规则可回到内置策略。
- 远程规则集必须配置固定 HTTPS URL 和预期 SHA-256。更新失败继续使用最后一个通过哈希与结构校验的缓存；移除远程来源即可停止后续加载。
- 最终规则预览展示实际生成顺序。基础设施防环路规则优先于用户规则；进程规则优先于域名/IP 用户规则；直连前缀和内置地域规则位于其后。

限制：最多 200 条用户规则；仅支持域名后缀和 IPv4 CIDR；远程文件最大 1 MiB且禁止重定向；哈希变化必须由用户显式更新。规范化后同一匹配项动作冲突会拒绝应用，不会选择其中一条。

## 进程分流

- 使用 `process-name` 匹配无路径分隔符的 `.exe` 名称，或使用 `process-path` 匹配绝对 Windows 可执行文件路径。
- 删除进程规则并重新应用即可停用。若名称对应多个运行路径、完整路径变化或进程信息权限不足，应用会给出明确诊断；不会退化为更宽泛的名称匹配。
- 子进程不继承父进程规则，实际联网的子进程需要单独配置。未命中进程规则的流量仍进入域名/IP 与内置策略，不会绕过整体分流。

限制：完整路径规则会受应用升级改路径影响；受保护进程可能只显示权限不足；当前不支持发布者、包标识或进程树匹配。

## 节点收藏与测速

- 在“代理”页切换收藏，按收藏、延迟或名称排序；“全部测速”最多并发探测 4 个节点。
- 再次切换可取消收藏。测速结果仅存在当前 UI 会话，重新打开应用即可清除，不影响节点选择或代理配置。
- 节点存储首次打开时由 Schema 1 原子迁移到 Schema 2，只新增 `favorite`；迁移失败不覆盖原文件。订阅刷新按协议、服务器和端口保留相同 endpoint 的收藏。

限制：测速是 HTTP CONNECT 可用性与延迟采样，不代表持续吞吐、UDP 能力或最终业务体验。

## 网卡 B 流量预算

- 在“设置”页启用月度预算，配置预算 GB 和提醒比例；“监控”页显示当月累计值。
- 关闭开关即可停用提醒，不修改核心路由。可执行“本月归零”重新建立本月计量基线；自然月切换也会自动归零。
- 达到提醒阈值和 100% 时各提醒一次。该功能只提醒，不会阻断网络。

限制：计量来自 Windows 网卡 B 收发总字节，包含其他应用流量，不等同于运营商账单，也不代表仅由 WinRouter 分流的流量。

## 界面语言

- 在“设置”页切换简体中文或英文，选择立即生效并保存于当前用户浏览器存储。
- 删除 `localStorage` 中的 `winrouter.locale.v1` 可恢复按浏览器首选语言选择；资源缺键回退到简体中文。

限制：首批翻译覆盖全局导航、状态、概览、监控、流量预算和设置；网卡、规则、代理与诊断页仍有中文业务文本。

## Windows 网络组件重置

- “设置”页的“高级网络修复”提供系统级网络组件重置。执行前必须经过两次确认，并自动停止 WinRouter 分流核心。
- 提权 helper 只执行固定的三步白名单命令：`netsh winsock reset`、`netsh int ip reset`、`ipconfig /flushdns`。前端不能传入命令、参数或路径；界面展示每一步的成功状态、退出码和输出。
- 操作完成后核心保持停止状态，并提示用户重启 Windows；该功能不会自动重新启动分流，也不会伪装成仅恢复 WinRouter 路由。

限制：`netsh int ip reset` 可能清除静态 IP、网关、DNS、VPN 或虚拟网卡配置，执行前应记录用户网络设置。实际系统命令和重启验收必须在用户授权的 Windows 环境中进行。

## 整体回滚

停止 WinRouter 会清理本产品创建的核心进程、TUN 和可验证网络资源。配置更新经过生成、校验、原子替换、健康检查和失败回滚；任何增强功能校验失败都不会提交部分配置。需要完全回到 Phase 3 行为时，删除自定义及进程规则、移除远程规则来源、关闭预算提醒，并忽略收藏和语言这两项仅影响 UI 的状态。
